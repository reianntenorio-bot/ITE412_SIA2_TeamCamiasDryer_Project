# K-Smart Store – E-commerce Client

Standalone e-commerce client for Kamyas products (dried Kamias, Kamyas Smart Machine, accessories).

## Setup

```bash
cd ecommerce-client
npm install
```

## Run

```bash
npm run dev
```

Runs at [http://localhost:5174](http://localhost:5174).

## Build

```bash
npm run build
```

## Deploy

Can be deployed independently (e.g. Vercel, Netlify). Add `kamyas.jpg` to `public/` for product images.
