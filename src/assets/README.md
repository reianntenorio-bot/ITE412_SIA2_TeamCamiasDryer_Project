# Assets Folder

Place your logo file here as `logo.png`

## Supported Formats
- PNG (recommended)
- SVG
- JPG/JPEG

## Recommended Logo Specifications
- **Login page logo**: 80x80px container (use square logo or 1:1 aspect ratio)
- **Dashboard navbar logo**: 48x48px container (use square logo or 1:1 aspect ratio)
- **Format**: PNG with transparent background (recommended)
- **File size**: Keep under 100KB for optimal performance

## Current File
- `logo.png` - Main logo file (add your logo here)

## Usage
The logo is automatically imported in:
- `src/pages/Login.jsx` - Large logo on login page
- `src/pages/Dashboard.jsx` - Small logo in navbar

If you need to change the logo file name, update the import statements in these files.
