\## Project



\*\*CAMIAS DRYER: An IoT-Based Drying System with E-Commerce for Agrigold Farm Learning Center Inc.\*\*



\## Project Overview



The Camias Dryer is an IoT-based drying system designed to improve the traditional drying process through temperature and humidity monitoring, automated drying control, real-time monitoring, solar-assisted power, and an integrated e-commerce platform.



\## Key Components to Present



\* IoT-based drying system

\* Temperature and humidity monitoring

\* Automated heating and ventilation control

\* Real-time monitoring dashboard

\* Drying records and history

\* Product and inventory management

\* E-commerce and online ordering

\* Firebase cloud services

\* Solar-assisted power system



\## Main Stakeholders

\* System Administrator/Staff

\* Customers

\* Local Farmers
